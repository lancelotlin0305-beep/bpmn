## 決策點

- **引用?**(排他)
  - （引用→是） → 點選引用,欄位資訊存入刑案管理系統
  - （引用→否） → 結束

## 流程連線

- 開始 → 完成起訴書或不起訴書
- 完成起訴書或不起訴書 → 執行列印或儲存
- 執行列印或儲存 → 產製書類PDF並拋轉至SFTP
- 產製書類PDF並拋轉至SFTP → SFTP(書類PDF)
- SFTP(書類PDF) → 批次撈取SFTP之書類PDF
- 批次撈取SFTP之書類PDF → AI智慧輔助系統判讀五類統計欄位
- AI智慧輔助系統判讀五類統計欄位 → 整理判讀結果並呼叫刑案管理系統API存入暫存檔
- 整理判讀結果並呼叫刑案管理系統API存入暫存檔 → 刑案管理系統暫存區
- 刑案管理系統暫存區 → 登入刑案管理系統
- 登入刑案管理系統 → 進入偵查類案件查詢個案
- 進入偵查類案件查詢個案 → 點選「AI引用」按鈕
- 點選「AI引用」按鈕 → 自暫存區讀取AI判讀結果
- 自暫存區讀取AI判讀結果 → 檢視判讀資料是否符合需求
- 檢視判讀資料是否符合需求 → 引用?
- 引用? —[引用→是]→ 點選引用,欄位資訊存入刑案管理系統
- 引用? —[引用→否]→ 結束
- 點選引用,欄位資訊存入刑案管理系統 → 結束

## 橫向系統分區

- **書類生成系統**:開始、完成起訴書或不起訴書、執行列印或儲存、產製書類PDF並拋轉至SFTP、SFTP(書類PDF)
- **AI智慧輔助系統**:批次撈取SFTP之書類PDF、AI智慧輔助系統判讀五類統計欄位、整理判讀結果並呼叫刑案管理系統API存入暫存檔
