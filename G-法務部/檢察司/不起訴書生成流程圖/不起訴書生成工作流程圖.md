# Pool:書類生成暨漢書系統

## 角色(泳道)

1. 檢察官

## 流程步驟

1. **開始**(起始事件|角色:檢察官)
2. **登錄書類生成系統**(任務|角色:檢察官)
3. **查詢並點開個案**(任務|角色:檢察官)
4. **由書類生成系統連線AI智慧輔助系統**(任務|角色:檢察官)
5. **書類生成系統須與AI智慧輔助系統完成帳號驗證,並同時傳遞個案資料與個案案號至AI智慧輔助系統**(註解|角色:檢察官)
6. **轉AI智慧輔助系統**(結束事件|角色:檢察官)
7. **AI回傳草稿**(起始事件|角色:檢察官)
8. **複製內文或下載後匯入漢書系統**(任務|角色:檢察官)
9. **不起訴書(定稿)**(輸出文件|角色:檢察官)
10. **完成**(結束事件|角色:檢察官)
11. **應以標準化介接直接匯入書類系統(現行人工匯入)**(註解|角色:檢察官)

## 流程連線

- 開始 → 登錄書類生成系統
- 登錄書類生成系統 → 查詢並點開個案
- 查詢並點開個案 → 由書類生成系統連線AI智慧輔助系統
- 由書類生成系統連線AI智慧輔助系統 → 轉AI智慧輔助系統
- AI回傳草稿 → 複製內文或下載後匯入漢書系統
- 複製內文或下載後匯入漢書系統 → 完成

# Pool:AI智慧輔助系統

## 角色(泳道)

1. AI智慧輔助系統

## 流程步驟

1. **接收書類系統個案資料**(起始事件|角色:AI智慧輔助系統)
2. **偵訊筆錄**(輸入文件|角色:AI智慧輔助系統)
3. **匯入卷證資料、移送書、偵訊筆錄與警詢筆錄**(任務|角色:AI智慧輔助系統)
4. **移送書**(輸入文件|角色:AI智慧輔助系統)
5. **警詢筆錄**(輸入文件|角色:AI智慧輔助系統)
6. **明確指定書類類型(不起訴書)**(任務|角色:AI智慧輔助系統)
7. **依案件類型自動選用書類範本**(任務|角色:AI智慧輔助系統)
8. **AI智慧輔助系統主動詢問不起訴原因**(任務|角色:AI智慧輔助系統)
9. **輸入不起訴原因**(任務|角色:AI智慧輔助系統)
10. **AI智慧輔助系統詢問適用法規條款(條/款)**(任務|角色:AI智慧輔助系統)
11. **選擇適用法規條款**(任務|角色:AI智慧輔助系統)
12. **AI智慧輔助系統生成不起訴書草稿**(任務|角色:AI智慧輔助系統)
13. **不起訴書草稿**(輸出文件|角色:AI智慧輔助系統)
14. **檢視草稿內容**(任務|角色:AI智慧輔助系統)
15. **直接調整草稿內文**(任務|角色:AI智慧輔助系統)
16. **檢視與調整之編修結果應回饋自動Fine-tuning機制,持續優化模型**(註解|角色:AI智慧輔助系統)
17. **回傳漢書系統**(結束事件|角色:AI智慧輔助系統)

## 流程連線

- 接收書類系統個案資料 → 匯入卷證資料、移送書、偵訊筆錄與警詢筆錄
- 匯入卷證資料、移送書、偵訊筆錄與警詢筆錄 → 明確指定書類類型(不起訴書)
- 明確指定書類類型(不起訴書) → 依案件類型自動選用書類範本
- 依案件類型自動選用書類範本 → AI智慧輔助系統主動詢問不起訴原因
- AI智慧輔助系統主動詢問不起訴原因 → 輸入不起訴原因
- 輸入不起訴原因 → AI智慧輔助系統詢問適用法規條款(條/款)
- AI智慧輔助系統詢問適用法規條款(條/款) → 選擇適用法規條款
- 選擇適用法規條款 → AI智慧輔助系統生成不起訴書草稿
- AI智慧輔助系統生成不起訴書草稿 → 檢視草稿內容
- 檢視草稿內容 → 直接調整草稿內文
- 直接調整草稿內文 → 回傳漢書系統

## 跨 Pool 訊息流(message flow)

- 回傳漢書系統 ⇢[不起訴書草稿內文]⇢ AI回傳草稿
